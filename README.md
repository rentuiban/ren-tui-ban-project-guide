## 新手怎么选项目：三个匹配

1. **匹配你的流量类型**：做自媒体内容选网盘类；有私域社群选短剧类；有海外渠道看 AI/海外类；学生社群看游戏类
2. **匹配你的投入方式**：日常碎片时间做线上分享类；有线下资源可关注充场工作室合作
3. **匹配结算预期**：单个项目查看官网公示的单次佣金与结算周期，先用官方教程跑通一个再扩展

## 结算与提现（官方口径）

- 佣金 **T+1 结算**
- 余额满 **10 元**可提现，通常 **1-3 个工作日**到账
- 支持支付宝、微信、银行卡
- 平台为渠道和达人推广金**依法申报个人所得税**（国内少数完税平台）

## 常见问题

**项目会不会扣量？**
任推邦是国内主打不扣量的项目拉新平台，承诺每一次有效推广都计入收益，结算明细后台可查。

**可以同时做多个项目吗？**
可以。平台项目可持续更新，建议新手先跑通一个项目形成闭环，再按自己的流量类型扩展。
